## Install in one line

Linux (x86_64 / arm64) or macOS. The installer adds tmux and git if they are missing, runs HermitHub
as a user service and prints a setup link. Open it, choose a password, and install an agent from
**Settings**.

<Tabs>
  <TabItem label="Standalone">
    <Code lang="bash" code="curl -fsSL https://raw.githubusercontent.com/suriyadi15/hermithub/main/install.sh | bash" />
  </TabItem>
  <TabItem label="Docker">
    <Code lang="bash" code="curl -fsSL https://raw.githubusercontent.com/suriyadi15/hermithub/main/install.sh | bash -s -- --docker" />
  </TabItem>
  <TabItem label="Docker + HTTPS">
    <Code lang="bash" code="curl -fsSL https://raw.githubusercontent.com/suriyadi15/hermithub/main/install.sh | bash -s -- --docker --domain hub.example.com" />
  </TabItem>
  <TabItem label="Ask your agent">
    Install the HermitHub skill, then ask *"Install HermitHub on this machine"*.
    <Code lang="text" code="/plugin install hermithub --marketplace suriyadi15/hermithub" />
    [Other agents →](/docs/ai-install/)
  </TabItem>
</Tabs>

## How it works

The browser talks to a small Bun server, and every agent runs inside a tmux session on that server. The
server runs as a standalone executable (a user service on your machine) or in a Docker container.

- **Two ways to run it.** The standalone executable needs only tmux and git and uses your own user
  account. The Docker image keeps agents in a container, and everything in `./data`.
- **Sessions are tmux sessions.** Closing the browser does not stop them, and neither does restarting
  the standalone service.
- **Every request** needs a logged-in session and must come from an allowed origin.

<Aside type="caution" title="It is a remote shell">
  The dashboard gives full shell access to your user account (standalone) or the container (Docker),
  including your agent and GitHub credentials. It listens on `127.0.0.1` by default. Expose it only over
  HTTPS, with a strong password, ideally behind Cloudflare Access or a VPN.
  [Read the security guide](/docs/security/).
</Aside>
